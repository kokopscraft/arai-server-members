テレポート申請・要請システム

テレポート申請・要請は、プレイヤー間で移動を承認してもらうシステムです。相手の明示的な承認が必要で、タイムアウト機能も搭載されています。

!tpr：テレポート申請（相手指定）

コマンド： !tpr <プレイヤー名またはハンドルネーム>

説明：特定のプレイヤーにテレポート申請を送信します。相手プレイヤーが yes または no で応答するまで待機します。

流れ：

  • 申請送信者がコマンド実行
  • 相手プレイヤーに通知が届く
  • 相手が yes で承認 → テレポート完了
  • 相手が no で拒否 → テレポート中止
  • 60秒以内に応答なし → 自動タイムアウト

!tpa：テレポート要請（全体公開）

コマンド： !tpa

説明：テレポート要請を全プレイヤーに公開します。複数の誰かが yes または no で応答できます。

備考：全プレイヤーに表示されるため、誰かが応答する可能性があります。

応答コマンド

コマンド説明タイミング
yesテレポート申請を承認申請を受け取ったら即座に実行
noテレポート申請を拒否申請を受け取ったら即座に実行
allowテレポート要請に応答（承認）要請を受け取ったら即座に実行
denyテレポート要請に応答（拒否）要請を受け取ったら即座に実行
申請がない状態で yes、no、allow、deny を実行しても何も起こりません。

Bindscord

Bindscordは、ワールド内の特定のプレイヤー間で会話ができる機能です。国家別のプライベートチャットグループに参加し、同じグループ内のメンバーと隔離された通信ができます。

アクセス方法

操作フロー：

  1. メインメニューを開く
  2. 「アプリケーション」を選択
  3. 「Bindscord」を選択
  4. 所属している国家（またはグループ）の名前をタップ

これにより、該当のプライベートチャットに接続できます。

現在のチャット状態

フォーム画面には「現在のチャット」が表示されます。これは現在接続しているチャットグループを示しており、このグループへのメッセージ送信時に自動送信されます。

チャットの特徴

  • 接続要件 — チャットを受け取るには、明示的に接続する必要があります。同じ国家に所属しているだけでは視認できません
  • 自動送信 — チャット接続中にメッセージを送信すると、接続しているチャットに自動で送信されます
  • 全体チャット常時表示 — 個別（国家別）チャットに参加していても、全体チャット（グループ0）は常に視認できます
  • PVP保護 — 同じチャットに接続している人同士は互いに攻撃できません

ワールドクリーンアップ

ワールドクリーンアップとは

ワールドクリーンアップ（WCU）は、サーバー内のワールドを整理するために20分周期で自動実行されるプログラムです。

削除対象：

  • ワールドに落ちているアイテム
  • 敵モブ（村人ゾンビ・スケルトンホース・エンダードラゴン・ウィザーを除く。ネザーではピグリンとピグリンブルートも対象外）
  • 経験値オーブ

全ロスを防ぐための対策

WCUで削除されず、アイテムやエンティティを保護する方法があります。

メインメニュー周辺の保護

メインメニューの付近7ブロック範囲に落ちているアイテムは自動削除されません。

特殊な名前の保護

エンティティに特殊な名前を付けることで、削除から保護できます：

  • keep — 最も一般的な保護方法
  • Dinnerbone / Grumm — バニラの逆さま表示と兼用
  • jeb_ / Toast / Johnny — バニラのイースターエッグ名
  • (A) と (1)〜(10)（(10). / (10).. / (10)... を含む）
  • [A] と [1]〜[10]（[10]. / [10].. / [10]... を含む）

上記の名前を付けたエンティティはWCUでは削除されません。複数のエンティティを区別したいときは、丸括弧・角括弧の連番が便利です。

名前は大文字・小文字まで完全に一致している必要があります。Dinnerbone は保護されますが、dinnerbone では保護されません。

ログ設定

残り時間ログの通知について：

定期的に表示される「WCU実行まで…分」というログは、メインメニューの「設定」から削除できます。

ただし、10秒前のアラートと実行通知は設定でオフにしても必ず届きます。重要な通知のため無視できません。

保護機能

保護機能とは

保護機能は、死亡してドロップしたアイテムを一定時間守るシステムです。死んだ瞬間に死亡地点の座標がチャットに表示され、そのまま保護モードが始まります。

死亡地点には炎のパーティクルが出続けるため、遠くからでも落とした場所を見つけられます。

保護モードの仕様

項目内容
保護時間5分間
他プレイヤーの回収不可（本人以外は拾えません）
ホッパーなどでの回収不可
インベントリの復元拾ったアイテムが死亡前と同じスロットへ自動で戻ります
回収完了全て拾うと「保護完了」が通知されます

リカバリーコンパス

保護モード中は、手持ちのメインメニューが一時的にリカバリーコンパスに変化し、死亡地点の方向を指し示します。

全てのアイテムを回収すると、コンパスは自動的にメインメニューへ戻ります。

保護時間の5分を過ぎると保護は解除され、以降は誰でも拾えるようになります。ワールドクリーンアップの削除対象にもなるため、早めの回収を心がけてください。

固有鉱石「オスミウム」について

オスミウムについて

オスミウムは、ワールドに追加されたカスタム鉱石素材で、ツールやアイテムのクラフティング用の重要なリソースです。標準的なマインクラフト素材と比べて、より高い耐久性と効果を備えています。

オスミウム鉱石

  • ブロックID： asa3:osmium_ore
  • 採掘時間：4秒（鉄以上のツルハシが必要）
  • ドロップ：オスミウムの原石 1〜3個（シルクタッチの場合はオスミウム鉱石がそのままドロップ）
  • 爆発耐性：3.0

鉱石の入手方法

クラフティングで作成

オスミウム鉱石は自然生成されないため、以下の石ブロックから作業台でクラフトできます：

  • 石（Stone）
  • 花崗岩（Granite）
  • 安山岩（Andesite）
  • 閃緑岩（Diorite）

これらの石ブロック9個を作業台にクラフトすることで、オスミウム鉱石1個を作成できます。

Core Protect

概要

新井鯖の「Hub」内にある「保護区画」の保護機能です。自分の土地を他のプレイヤーから保護し、権限を細かく設定できます。

基本的な使い方

!coreprotectか短縮形!cpでフォームを開けます。自分がエディターに指定されている土地を閲覧でき、他の人を招待することもできます。

エディター権限について

エディターに指定されていないプレイヤーは、保護区画内のブロック破壊とインタラクトができません。

インタラクトとは以下の操作を指します：

  • 新たなブロックの設置
  • 作業台の使用
  • チェストのオープン
  • 額縁の中身を回す

オプション機能：警告をチャットからフォームに変更することも可能で、マクロなどでも突破できない強固なセキュリティになります。

保護区画のID

保護区画は自動でIDが振り分けられます。「メインメニュー」の「G Warp」では区画を閲覧することはできませんが、IDを控えておけばチャットコマンドでその区画にテレポートできます。

例： !gwarp a0001

テレポート位置：エディターが自由に決めることができます。区画の中かその付近にしか指定できません。

ブロック権限の設定

エディターは特定のブロックの破壊・インタラクトをエディターに指定されていないプレイヤーに許可することができます。

例： minecraft:leverを「インタラクト可能」に追加すれば、レバーだけを引くことができる区画が完成します。

基本的なアイテムID

ブロックアイテムID
チェストminecraft:chest
樽minecraft:barrel
額縁minecraft:frame

由来

「Core Protect」は本来Java版に存在するプラグインの名前です。全プレイヤーの行動（ブロックの設置・破壊など）をデータベースにログとして記録し、荒らし被害が発生した際にその箇所をロールバック（巻き戻し・復元）できる、荒らし対策に特化したプラグインです。

新井鯖では区画を保護するという意味で名前をお借りしました。
